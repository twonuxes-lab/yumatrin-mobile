# YUMATRIN MOBILE

Официальный сайт мобильного игрового проекта **YUMATRIN MOBILE**.

## 🚀 О проекте
Это тестовая версия веб-сайта, созданная для презентации проекта. Сайт включает в себя:
*   Главную страницу
*   Раздел с серверами
*   Страницу скачивания (в разработке)
*   Энциклопедию мира игры (Гос. структуры, ОПГ, Бизнесы и т.д.)
*   Форму регистрации
*   Политику конфиденциальности

## 🛠 Технологии
*   HTML5
*   CSS3 (Flexbox, Grid, адаптивный дизайн)
*   JavaScript (Vanilla JS)

## ⚠️ Статус
Проект находится в стадии активной разработки.
